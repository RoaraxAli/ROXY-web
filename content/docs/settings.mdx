title: Settings
description: What each settings tab controls.
---

| Tab | What you can change |
|---|---|
| General | Auto-titling, send-on-enter, token display, system prompt, temperature, history limit, streaming. |
| Models | Defaults, provider enable/disable, model visibility and prefixes. |
| CLI | Working directory, permission mode, timeout, agent detection. |
| Appearance | Accent colour, font scale, compact layout, chat width, motion. |
| Data | Open the data folder, export or reset. |
| About | Version, update check, provider catalogue credits. |
