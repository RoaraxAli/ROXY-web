Concepts

Three words cover most of the app.

TermWhat it means
SessionOne conversation. It stores every message, the provider and model that answered each turn, and token counts.
ProviderA source of models: an OpenAI-compatible API, a local agent CLI, or the 9Router endpoint. Providers are what the picker lists.
RouteThe provider + model currently answering. Changing the route never edits the transcript.

When you switch models mid-thread, ROXY inserts a small handoff marker in the transcript and replays the full user/assistant history to the new model. Nothing is summarised or dropped.

Providers

Open Models → API models. The catalogue ships offline, so it works without a network call.

  1. Pick a provider card

    Search the catalogue or use “Any other OpenAI-compatible endpoint” for a private gateway.

  2. Paste a key

    Stored in config.json on your machine. You can also leave it blank and rely on the provider's environment variable.

  3. Refresh models

    ROXY calls the provider's /models endpoint and fills the picker. If the provider does not implement it, type the model id manually.

  4. Choose a default model

    Select it in the card, then use the composer picker per session.

Local endpoints need no key. Anything on 127.0.0.1, localhost or [::1] is treated as trusted-local and shown as local.

OpenCode integration

OpenCode is the agent runtime ROXY drives. Install it once; API-model turns can then run through it.

  • ROXY passes a per-turn provider definition to OpenCode's inline config.
  • The API key is supplied only to that child process — your saved OpenCode auth files are untouched.
  • If OpenCode is not installed, ROXY falls back to its own OpenAI-compatible HTTP client.
  • Models reported by opencode models appear in the picker with their provider/model ids.
Sign-in is separate. OpenCode provider sign-in (for example ChatGPT) is an interactive step in your terminal. ROXY opens it for you and then refreshes the model list.

9Router & model priority

9Router is a local router exposing many providers behind one endpoint. ROXY adds the part it cannot know: your ranking.

The endpoint

ROXY talks to http://localhost:20128/v1 and reads models from /v1/models. The dashboard lives at http://localhost:20128.

Setup

  1. Install

    Models → API models → 9Router card → Install (npm package 9router). Requires Node.js.

  2. Start the server

    Press Start server, or run 9router yourself. The card switches to online after a refresh.

  3. Add providers

    In the 9Router dashboard, connect the accounts you want it to route across.

  4. Rank models

    Back in ROXY, press Refresh, then order the models with ↑ / ↓.

What ranking does

Each turn tries your selected model first, then the rest of the ranking in order. If a request fails — connection error, HTTP error, or a provider error frame — before any text has streamed, ROXY silently retries the next model in the list. Once tokens have started, the reply is left alone and the error is shown instead of switching mid-answer.

Ranking is stored, not guessed. The order lives in config.json under the provider's priority list and is used identically by the picker and the fallback loop.

Sessions

Create

New chat in the rail, or Ctrl/⌘ + N. Titles derive from your first message unless you turn that off.

Organise

Search the session list, rename inline, pin, archive or delete. Deletion asks first by default.

Switch model

The model button above the composer opens a searchable picker grouped by provider. No “Auto” entry — you always see what will answer.

Stop

Esc or the stop button cancels the request; for CLIs it terminates the child process.

FAQ

Does ROXY store my conversations in the cloud?

No. Sessions are JSON files in your local data folder. The only network traffic is to the providers you configured.

Can I use ROXY entirely offline?

The UI and catalogue work offline. Model calls need either a local server (9Router, Ollama-style endpoints) or a reachable provider.

How do I remove an agent CLI?

Models → CLI agents → open the agent → Uninstall. It only removes ROXY's managed copy.

Why is there no “Auto” model?

Auto hides which model answered. ROXY shows every route explicitly; automatic behaviour belongs to the 9Router priority list, where you can see and edit the order.

Where do I report a bug?

github.com/RoaraxAli/ROXY/issues — include your OS, ROXY version from Settings → About, and the steps to reproduce.
