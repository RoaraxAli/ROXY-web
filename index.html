Why ROXY

Stop re-explaining your work to a new model.

Every AI tool wants its own window, its own history and its own context. ROXY keeps one thread and lets the model behind it change. When a quota runs out or a provider is degraded, the conversation does not restart.

01

Shared context

Switching model never drops a message. The whole transcript is replayed to whichever provider answers next.

02

Priority routing

Rank the models you trust. 9Router walks that order and falls through automatically when one is rate-limited or down.

03

Bring your own keys

40+ OpenAI-compatible providers from a built-in catalogue. Keys stay on your machine, in your own config folder.

Built on OpenCode & 9Router

Two engines, one window.

ROXY is the interface. Under it, OpenCode runs as the agent runtime and 9Router keeps model traffic flowing. You install a tool once; ROXY keeps using it for every session.

OpenCode

The agent runtime ROXY drives headlessly. Install it from Models → CLI agents; hosted API turns are routed through OpenCode's own configuration without touching your saved auth files.

How OpenCode integration works →

9Router

A local router on localhost:20128 that exposes 40+ providers behind one OpenAI-compatible endpoint. ROXY reads its model list and lets you rank it.

Model priority and fallback →

Local by default. ROXY talks to localhost or straight to the provider you configured. There is no ROXY cloud, no relay, and no telemetry.

Questions

Before you download.

Is ROXY free?

Yes. ROXY itself is open source and free. You pay only for the model providers you connect — or use the free tiers some of them offer.

Does it send my data anywhere?

No. ROXY has no telemetry and no backend. Requests go directly to the endpoint you configured, or to a router running on your own machine.

Why does Windows warn about the download?

The builds are not code-signed yet, so Windows cannot show a verified publisher. Every release publishes SHA-256 checksums so you can verify the file you downloaded. See verifying a download.

Do I need OpenCode or 9Router?

No. ROXY works with plain API providers on its own. OpenCode adds the agent runtime; 9Router adds multi-provider priority fallback.
